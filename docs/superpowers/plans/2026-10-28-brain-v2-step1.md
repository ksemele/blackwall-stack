# Brain v2 step 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Brain v1 (stdlib script tailing `alerts.json`) with a containerised Python package that polls the Wazuh indexer, gets a structured verdict from any model backend, and sends a readable HTML Telegram message.

**Architecture:** Package `blackwall-brain/src/brain/`: `verdict` (schema, parsing), `models` (vendor-neutral interface + `anthropic` and `openai_compat` adapters), `analysis` (prompt, retries), `message` (Telegram HTML), `indexer` + `state` (polling intake), `telegram`, `config`, `main` (loop). Built into an image on the target by the `brain-analyst` role and run by a systemd unit (`podman run`). Config comes from an env file rendered by Ansible.

**Tech Stack:** Python 3.12, `anthropic` and `openai` SDKs (inside adapters only), `httpx` (indexer, Telegram), pytest, podman, Ansible.

**Spec:** `docs/superpowers/specs/2026-10-28-brain-v2-eval-design.md` (sections 4–7; step 1 of section 11).

## Global Constraints

- Only `src/brain/models/anthropic_model.py` imports `anthropic`; only `src/brain/models/openai_compat.py` imports `openai`. No other module knows a vendor format.
- Wazuh/indexer access is read-only. Brain never writes to the indexer or the API.
- No real hosts, IPs or domains in code, tests or docs: lab names `black-*`, lab range `172.28.0.0/24`, documentation ranges.
- Telegram `parse_mode: HTML`; every dynamic field passes through `html.escape`.
- Defaults stay Claude: backend `anthropic`, model `claude-haiku-5-5`, option `effort: low`, `max_tokens: 2048`.
- `PROMPT_VERSION = "2026-10-28.1"` in `analysis.py`, logged with every verdict.
- Dependencies pinned with hashes in `blackwall-brain/requirements.lock`; base image pinned by digest.
- Repo docs, comments, commits in English; brief conventional commits, one step each. Update every README/doc that references a changed command in the same commit (repo `CLAUDE.md` rule).
- Read `blackwall-brain/STATUS.md` before starting (repo rule).

## Review Focus

1. Indexer down, 401 or TLS error mid-run → logged, cursor unchanged, retried next poll, no crash, no lost alerts (test in Task 5).
2. A burst bigger than one page (e.g. 500 alerts after provisioning) → all processed in timestamp order across polls, none skipped (Task 5).
3. Model wraps JSON in ```` ```json ```` fences or adds prose, or returns an unknown enum → fences/prose stripped; invalid → one retry, then fallback message (Tasks 1, 3).
4. Hostile or huge alert fields (`<script>`, `&`, 20 kB `full_log`) → escaped, message ≤ 4096 chars (Task 4).
5. State file missing, empty or corrupt → warn, start from the backfill window, keep running (Task 5).

  - `format_verdict_message(alert: dict, doc_id: str, v: Verdict, dashboard_url: str, links: dict) -> str`
  - `format_fallback_message(alert: dict, doc_id: str, reason: str, dashboard_url: str, links: dict) -> str`
  - `MAX_LEN = 4096`

Layout (exact; tests assert it):

```
{icon} <b>{SEVERITY}</b> · <code>{host}</code> · {verdict text}
{summary}
Category: {category} · confidence: {confidence}
Action: {action}
Missing: {needs joined with "; "}            ← only if needs
Rule {rule.id} (level {rule.level}): {rule.description} · {timestamp UTC, "YYYY-MM-DD HH:MM UTC"}
🔗 <a href="{alert link}">Alert in dashboard</a> · <a href="{url}">{title}</a> …   ← line only if any link
```

- `icon`: `critical` 🟥, `high` 🔴, `medium` 🟠, `low` 🟢. `verdict text`: `true positive`, `false positive`, `needs a look`.
- `uncertain` → icon 🟡 and `needs a look` regardless of severity (spec §5, yellow alert).
- Fallback: first line uses `level_to_severity(rule.level)` and its icon, then `<i>AI analysis unavailable: {reason}</i>`, then the Rule line, then `<pre>{full_log[:300]}</pre>`, then links.
- Escape every dynamic value with `html.escape`; URLs with `html.escape(url, quote=True)`. If the result exceeds `MAX_LEN`, shorten `summary`/`action`/`needs` (and `full_log` in fallback) — never cut inside a tag.

### Task 5: Indexer intake and state

**Files:**
- Create: `blackwall-brain/src/brain/indexer.py`, `blackwall-brain/src/brain/state.py`
- Test: `blackwall-brain/tests/test_indexer.py`, `blackwall-brain/tests/test_state.py`

**Interfaces:**
- Produces:
  - `state.State` — `cursor: str | None` (raw `timestamp` string of the last processed alert), `seen: list[str]` (indexer `_id`s, newest last).
    `State.load(path: str, max_ids: int) -> State` (missing/empty/corrupt → empty state + WARNING log; Review Focus 5); `State.mark(doc_id: str, timestamp: str)`; `State.is_seen(doc_id) -> bool`; `State.save(path)` atomic (temp file + `os.replace`), keeps the newest `max_ids`.
  - `indexer.build_query(since: str, min_level: int, ignore_rule_ids: list[str], size: int) -> dict` — `bool.filter`: `range rule.level gte min_level`, `range timestamp gte since`; `must_not`: `terms rule.id`; `sort timestamp asc`; `size`.
  - `indexer.IndexerClient(url: str, user: str, password: str, verify: bool | str, client: httpx.Client | None = None)`; `.search(query: dict) -> list[tuple[str, dict]]` — `(_id, _source)` from `POST {url}/wazuh-alerts-*/_search`. Non-200, timeout, TLS → `IndexerError`.
  - `indexer.poll_once(client, state, *, min_level, ignore_rule_ids, overlap_s=10, max_backfill_s=3600, page_size=200, now=datetime.now(UTC)) -> list[tuple[str, dict]]` — the new alerts to process, in order:
    - `since = max(cursor - overlap_s, now - max_backfill_s)`; no cursor → `now - max_backfill_s`.
    - drop hits already in `state.seen`.
    - Does **not** mark them; the caller marks each after handling, so a crash mid-batch re-delivers only unhandled ones.
    - If the page was full and all hits were seen, query again from the last hit's timestamp (no overlap) until a page has unseen hits or is not full (Review Focus 2).
